Bounded authority for autonomous agents.

Monad AgentGuard lets an agent propose and execute a task while policy, escrow and an independent verifier decide whether authority is released. The planner can suggest; it cannot certify its own work.

Two real Agent workloads, one bounded execution layer

TreasuryPlanner can hire different seller Agents without changing the authority boundary. Policy decides first; Monad settles only after task-specific independent verification.
